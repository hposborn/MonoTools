Using MonoTools
=====================================

MonoTools is a package for exoplanet astronomers to manage planets of uncertain periods. 
It deals with the detection, vetting, model fitting and plotting of these long-period planets.

The package was written and is maintained by `Hugh Osborn <https://hughosborn.co.uk/about>`_ and hosted on `GitHub <https://github.com/hposborn/monotools>`_. 
Please forward any questions to `hugh.osborn[​at​]unibe.ch`.

Follow the `lightcurve <using_lightcurve.ipynb>`_ tutorial notebook to get a sense of how the TESS/K2/Kepler/CoRoT lightcurve access module works. Then follow one of the four MonoTools examples: `A duotransit <Example_1_Duotransit_Example.ipynb>`_, `a duotransit and monotransit <Example_2_Monotransit_and_duotransit.ipynb>`_, `an ambiguous 5-transit star <Example_3_Model_Ambiguous_Transits_simple.ipynb>`_, and `the same 5-transit lightcurve with TTVs \& GPs <Example_4_Modelling_Ambiguous_Transits_with_TTVs_and_GPs.ipynb>`_.
